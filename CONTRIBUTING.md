# Contributing

Thanks for helping improve these diagrams!

- **Spotted a technical error or a broken link?** Open an issue with the diagram name, what's wrong, and a source (spec, docs or paper) if you have one.
- **Topic suggestions** are welcome as issues labeled `topic-request`.
- Please don't open PRs that edit the PNGs directly. They're generated from source, so corrections are redrawn and re-exported.
- By contributing text fixes you agree they're licensed under the repo's license (CC BY-NC 4.0).
